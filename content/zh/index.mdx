# 概述

欢迎来到 **Utoo** 文档！

Utoo 是一个统一的前端工具链，包含三个集成组件：

| 包 | 描述 |
|---|------|
| [utoo](/zh/docs/utoo) | 快速、兼容 npm 的包管理器 |
| [@utoo/pack](/zh/docs/utoopack) | 高性能打包工具，支持 HMR |
| [@utoo/web](/zh/docs/utooweb) | 基于 WebAssembly 的浏览器原生打包 |

## 快速开始

```bash filename="Terminal" copy
# 全局安装 utoo
npm install -g utoo

# 安装项目依赖
ut install

# 运行脚本
ut dev
ut build

# 执行远程包
utx create-react-app my-app
```

## 为什么选择 Utoo？

- **快速** - Rust 驱动的高性能
- **兼容** - npm 的直接替代品
- **统一** - 一套工具链满足所有需求
- **现代** - 原生 ESM、TypeScript 等

## 包管理性能快照

以下数据来自 2026-08-27 的 `ant-design` 阶段化安装基准，Linux China x86_64 环境直连 `https://registry.npmmirror.com`，耗时越低越好。

| 场景 | utoo | Bun | pnpm 10 | pnpm 12 | aube |
|------|------|-----|---------|---------|------|
| 完全冷启动 (`p0`) | **12.04s ± 1.25s** | 19.63s ± 1.32s | 33.88s ± 0.64s | 18.50s ± 6.22s | 26.47s ± 7.65s |
| 仅 lock 冷启动 (`p3`) | **22.28s ± 12.71s** | 31.75s ± 15.11s | 40.70s ± 11.64s | 31.67s ± 10.09s | — |
| 热缓存安装 (`p4`) | **1.22s ± 0.07s** | 4.58s ± 0.32s | 9.86s ± 0.48s | 2.60s ± 0.09s | — |

utoo 在三个有效安装场景中的均值都最快；`p0` / `p3` 是高方差的方向性结果，`p4` 的领先信号最稳定。aube 的 `p3` / `p4` 因缺少预期 lockfile 被拒绝。GitHub Actions npmjs 全量结果详见 [utoo 性能基准](/zh/docs/utoo/performance)。

## 安装

**包管理器**

```bash filename="Terminal" copy
npm install -g utoo
```

**打包工具**

```bash filename="Terminal" copy
ut install @utoo/pack --save-dev
```

**浏览器打包工具**

```bash filename="Terminal" copy
ut install @utoo/web
```
