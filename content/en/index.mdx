# Overview

Welcome to the **Utoo** documentation!

Utoo is a unified frontend toolchain combining three integrated components:

| Package | Description |
|---------|-------------|
| [utoo](/en/docs/utoo) | Fast, npm-compatible package manager |
| [@utoo/pack](/en/docs/utoopack) | High-performance bundler with HMR |
| [@utoo/web](/en/docs/utooweb) | Browser-native bundling via WebAssembly |

## Quick Start

```bash filename="Terminal" copy
# Install utoo globally
npm install -g utoo

# Install project dependencies
ut install

# Run scripts
ut dev
ut build

# Execute remote packages
utx create-react-app my-app
```

## Why Utoo?

- **Fast** - Rust-powered performance
- **Compatible** - Drop-in npm replacement
- **Unified** - One toolchain for all needs
- **Modern** - Native ESM, TypeScript, and more

## Package-manager benchmark snapshot

These numbers come from the 2026-08-27 phased install benchmark for the `ant-design` project in a Linux China x86_64 environment connected directly to `https://registry.npmmirror.com`. Lower is better.

| Scenario | utoo | Bun | pnpm 10 | pnpm 12 | aube |
|----------|------|-----|---------|---------|------|
| Full cold (`p0`) | **12.04s ± 1.25s** | 19.63s ± 1.32s | 33.88s ± 0.64s | 18.50s ± 6.22s | 26.47s ± 7.65s |
| Lock-only cold (`p3`) | **22.28s ± 12.71s** | 31.75s ± 15.11s | 40.70s ± 11.64s | 31.67s ± 10.09s | — |
| Warm (`p4`) | **1.22s ± 0.07s** | 4.58s ± 0.32s | 9.86s ± 0.48s | 2.60s ± 0.09s | — |

Utoo has the fastest mean in all three valid install states. The high-variance `p0` / `p3` results are directional, while the `p4` lead is the strongest signal. Aube's `p3` / `p4` cells were rejected because the expected lockfile was missing. See [utoo performance benchmarks](/en/docs/utoo/performance) for the full GitHub Actions npmjs results.
