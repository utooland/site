# utoo

import { Callout, Cards, Tabs } from 'nextra/components'

utoo (`ut`) is a fast, modern package manager for JavaScript projects, providing npm-compatible package management with performance optimizations.

<Callout type="info">
  utoo is a drop-in replacement for npm with better performance.
</Callout>

## Installation

<Tabs items={['macOS / Linux', 'Windows', 'npm']}>
  <Tabs.Tab>
    No Node.js required. Install with a single command:

    ```bash filename="Terminal" copy
    curl -fsSL https://utoo.land/install | bash
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    Run in PowerShell:

    ```powershell filename="PowerShell" copy
    irm https://utoo.land/install.ps1 | iex
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    If you already have Node.js installed:

    ```bash filename="Terminal" copy
    npm install -g utoo
    ```
  </Tabs.Tab>
</Tabs>

## Quick Start

### 1. Install dependencies

```bash filename="Terminal" copy
ut install
```

### 2. Add a package

```bash filename="Terminal" copy
ut install lodash
ut install -D typescript
```

### 3. Run scripts

```bash filename="Terminal" copy
ut build
ut dev
```

### 4. Execute remote packages

```bash filename="Terminal" copy
utx create-react-app my-app
```

## Performance comparison

`utoo` is optimized around dependency resolution, download reuse, and global package-cache reuse. The table below shows a phased install benchmark for the `ant-design` project on poolab Linux x86_64, connected directly to `https://registry.npmmirror.com`. Lower is better.

| Scenario | utoo | Bun | pnpm | aube |
|----------|------|-----|------|------|
| Full cold (`p0`) | **7.84s ± 2.17s** | 13.21s ± 2.36s | 39.32s ± 16.56s | 27.63s ± 6.47s |
| Lock-only cold (`p3`) | 6.64s ± 1.64s | 8.62s ± 3.57s | 15.14s ± 0.77s | **6.42s ± 0.31s** |
| Warm (`p4`) | **1.09s ± 0.05s** | 2.72s ± 0.05s | 7.89s ± 0.38s | 1.60s ± 0.07s |

In `p3`, the utoo and aube mean difference is within noise and should be treated as a tie. Utoo is more clearly ahead in `p0` and `p4`. Absolute timings vary by platform, registry, and network topology. See [performance benchmarks](/en/docs/utoo/performance) for the full methodology, GitHub Actions npmjs runs, and corrected pnpm validation.

## Features

### Global Cache

Installed packages are cached by `package/version` in `~/.cache/nm/`. Subsequent installs hard-link directly from the cache, skipping download and extraction. Each version is stored only once on disk, shared across projects.

```
~/.cache/nm/
├── lodash/4.17.21.tgz
├── react/18.3.0.tgz
└── typescript/5.6.0.tgz
```

### Registry Acceleration

When the configured registry is cnpm-compatible (`registry.npmmirror.com` and similar), utoo automatically enables two optimizations: **semver query acceleration** (server-side version resolution) and **binary mirror** (native-module downloads redirected to a CDN). Both are off on the official npm registry.

See [Registry Acceleration](/en/docs/utoo/registry-acceleration) for how each works, and [`ut ping`](/en/docs/utoo/commands#ping) to probe a registry from the CLI.

### Migrate from pnpm

One command to migrate from a pnpm project, automatically converting workspaces, overrides, and catalog configuration from `pnpm-workspace.yaml`:

```bash filename="Terminal" copy
ut install --from pnpm
```

See [Migrating from pnpm](/en/docs/utoo/migration) for details.

## Shortcut Execution

<Callout>
  You can run package.json scripts directly without `run`:
</Callout>

```bash filename="Terminal" copy
ut build      # same as: ut run build
ut dev        # same as: ut run dev
ut test       # same as: ut run test
```
