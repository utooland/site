01 / 一套工具，三个环节

你的开发日常，
可以更轻快。

从本地开发、CI 到浏览器，
让想法更快成为可运行的应用。

01↓

utoo

依赖安装，
少一点等待。

Rust 原生包管理器，以并行下载和全局缓存连接多个项目，继续使用标准 npm 锁文件。

  • 并行下载与版本级全局缓存
  • 兼容 package-lock.json
  • 支持 Monorepo 工作区
Rust 原生包管理器
02ϟ

@utoo/pack

改一点，
只更新相关部分。

基于 Turbopack 的构建工具，沿依赖关系处理代码变更，把反馈留在创作的节奏里。

  • 开发编译与热更新
  • 增量构建与持久化缓存
  • 生产构建与产物分析
增量构建引擎
03⌘

@utoo/web

把开发环境，
装进浏览器。

通过 WebAssembly，在浏览器内完成依赖安装、TypeScript 编译、打包与实时预览。

  • 浏览器内安装 npm 依赖
  • WASM 原生编译与构建
  • 代码修改与实时预览
浏览器原生开发环境
